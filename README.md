# UberClone Driver

App móvil de conductor inspirada en Uber, hecha con React Native y Expo (SDK 57).

## Instalación
npm install
npx expo start

## Variables de entorno
Copia `.env.example` a `.env` y completa los valores. El archivo `.env` nunca se sube a Git.

## Uso de IA
Este proyecto usó herramientas de IA. Ver la [bitácora completa](docs/AI_LOG.md).
